# 检验技术员画像与资格口径校准

2026-10-28，业务方在本次修复会话中确认：2026.09.20 的社招、应届岗位 DOCX 为当前正式版本；社招“3年以上试剂管理经验”为优先项；应届生具备报考资格但尚未报名，可以进入推荐，其他要求仍需满足。

正式资料保持私有，不随公开源码发行。新版私有资产包以已批准 DOCX 为业务来源，保留其原件和哈希；为兼容既有 PDF 生成流程，创建全文核对一致、嵌入中文字体的 PDF 派生件，再重建画像库和来源 manifest。旧 PDF 及旧库保留快照，不能仅手改生成 JSON 或继续沿用旧来源哈希。

- 社招：6 项能力、3 项经验、4 项特质，共 13 项。
- 应届：5 项能力、2 项经验、4 项特质，共 11 项。
- 其余 12 条画像保持不变；两个稳定 profile_id 保留。
- 社招试剂管理经验继续为 `preference`，不新增否决条件。

应届报考资格使用独立状态 `eligible_to_apply`，仅在明确匹配、且成功解析到同一已核验应届画像时启用。歧义、未匹配或解析失败时不得仅凭残留画像ID授予例外。它表示有逐字事实支持的报考资格，不表示已经报名、通过考试或取得证书。输出仍提示人工核实资格；没有证据或无法 grounded 的结论降为 `unknown`，不能仅凭学历/专业推定资格。

该状态不放宽社招资格要求；既有证书过期、明确无证、资格未知及其他条件的处理保留。证据契约验证、grounding 和 Python 最终决策的分工不变。

私有资产包应与校准后的代码配套验收、安装；本地形成新版资产包不代表已替换任何现有 main 工作区、生产资产或已部署服务。真实消息投递、OCR 和历史公开链接撤销仍需单独验收及授权。
