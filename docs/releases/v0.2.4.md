# Recruiter-Na v0.2.4

日期：2026-10-29。源码分支 release/v0.2.4，tag v0.2.4；工作流合同仍为5.0.2。

每位推荐人末尾独立提供原始简历下载链接，前后空行；首批、换批及重显当前批统一生成，不改变决定、推荐顺序、游标或选择状态。选中后的回复不重复放下载链接，原有文件投递保留。

用户无法取得钉钉后台配置权限，明确要求恢复原来的直接下载体验。生产使用显式 link 模式：持有效链接即可下载，包括转发后的持有者；不声称已验证企业身份，不需要 OAuth 回调或成员查询权限。随机票据256位、最多24小时有效、仅存摘要，不把原件复制到公开静态目录。每次下载重查原owner需求、已展示候选和原件指纹；需求删除、候选撤销、文件变更或链接过期后拒绝。招聘需求管理仍严格owner-scoped。

可选owner/corporate模式保留，未启用，不能混用不同模式的票据。首次显示与重新显示产生独立有效票据；过期可要求重新显示本批候选人。
